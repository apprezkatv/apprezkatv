# HDRezka Android App

**Неофициальный клиент** для просмотра фильмов, сериалов, мультфильмов и аниме с сайта HDRezka на **Android TV**, приставках и смартфонах.

**Удобный интерфейс · Поддержка пульта · Продолжение просмотра · Голосовой поиск**

## Возможности

### Каталог и поиск

- Фильмы, сериалы, мультфильмы, аниме  
- Полнотекстовый поиск по названию  
- Голосовой поиск (на устройствах с поддержкой)  
- Фильтры: жанры, страны, годы  
- Случайный фильм / случайный тайтл  
- «Продолжить просмотр»  
- Избранное + история просмотра

### Страница тайтла

- Полное описание  
- Выбор озвучки / перевода  
- Сезоны и серии (для сериалов)  
- Постер, кадры, дополнительные материалы  
- Быстрый переход к просмотру / продолжению

### Видеоплеер

- Выбор качества (1080p, 720p и др. — зависит от источника)  
- Переключение озвучек  
- Субтитры: выбор языка / отключение  
- Скорость воспроизведения: 0.5× … 2×  
- Масштабирование: подогнать / заполнить / увеличить  
- Перемотка:  
  - D-Pad (влево/вправо) на пульте  
  - свайп / тап по таймлайну на тач-устройствах
- Предпросмотр кадров при перемотке (если есть на сервере)  
- Автоматическое продолжение с последнего места

### Управление и интерфейс

- Полная поддержка **Android TV** (фокус, навигация, диалоги)  
- Удобная работа с пультом (D-Pad, OK, Back)  
- Полноценная поддержка тач-экранов  
- Голосовой поиск (системный)  
- Интеграция с Android TV channels (запуск из ТВ-интерфейса)

## Требования

- Android 7.0+ (API 24 и выше)  
- Желательна поддержка Android TV (для оптимального опыта)  
- Стабильное подключение к интернету

## Установка

1. Скачайте актуальный `.apk` из раздела **[Releases]**
2. Разрешите установку из неизвестных источников (если система запросит)
3. Установите приложение
4. Запустите и наслаждайтесь

**Обновление**  
Просто установите новую версию поверх старой — настройки и история обычно сохраняются.  
При проблемах можно удалить старую версию и поставить заново (прогресс будет потерян).

## Важные примечания

- Это **неофициальное** приложение-клиент к сайту HDRezka.ag  
- Всё видео, субтитры, постеры и метаданные загружаются **напрямую с серверов HDRezka**  
- Автор приложения **не распространяет** и **не хранит** видеофайлы  
- Доступность озвучек, качества видео, субтитров и превью-кадров зависит исключительно от сайта HDRezka и может меняться в любой момент
